# Control Shape

You can modify your shape directly in the viewer by **dragging shape points** — single or multiple at once.

![Drag shape points](/img/AfterFX_bkfrjPI6C1.gif)

## Working with Tangents

| Action | Shortcut |
|---|---|
| Add tangent (no tangent on point) | Select point → `Ctrl + Click` |
| Move tangent | Drag and drop a tangent handle |
| Move individual tangent | `Alt + Drag` a tangent handle |
| Remove tangent | Select point → `Ctrl + Click` |

![Tangent manipulation](/img/AfterFX_AYAOthkE10.gif)
