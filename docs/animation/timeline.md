# Timeline

:::note
Animation key management is primarily done in After Effects.  
The Shapper timeline is designed to **preview** the animation within the extension.
:::

## Timeline Shortcuts

| Key | Action |
|---|---|
| `J` | Previous keyframe |
| `K` | Next keyframe |
| `<` `>` | Frame by frame |
| `Space` | Play / Pause |
