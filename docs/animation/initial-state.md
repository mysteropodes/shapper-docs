# Initial State Button

The **"Initial State"** button restores the original positions of the masks as recorded during the first import via the "Mask Influence" button.

- Any influences or shape modifications made afterwards are **preserved**.
- Only the **initial mask positions** are restored.
- A keyframe is modified or added at the **current time** for the relevant masks.
