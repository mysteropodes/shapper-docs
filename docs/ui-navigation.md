# 🧭 UI Navigation

## Viewer — Zoom and Pan

| Action | How |
|---|---|
| **Zoom** | Mouse wheel — cursor position sets zoom center |
| **Drag / Pan** | Press middle mouse button and drag |
| **Reset** | Double-click in the middle of your shape |

## Undo

The undo button holds a **history of 10 actions**, covering:
- Mask transformations
- Shape modifications
- Influence changes
