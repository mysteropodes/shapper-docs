# 📦 Installation

## Install the Extension

1. Download and install the free [ZXP Installer](https://aescripts.com/learn/zxp-installer/) from aescripts.com.
2. **Close After Effects.**
3. Open ZXP Installer, go to `File > Open`, navigate to the **com.Shapper_1.cep.zxp** file from your download and install it — or simply drag and drop it.
4. Open After Effects and go to `Window > Extensions`, then click **Shapper**.

## Licensing

- Enter the **email** used to purchase Shapper and the associated **license key**.
- **One licence per machine.** You can revoke a machine from your account to transfer to another.
