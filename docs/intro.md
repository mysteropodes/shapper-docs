# Shapper Help Guide

**Precise Rigs, Endless Perspective**

![Shapper Banner](/img/PShaper_promo_16_copie.png)

:::info What is Shapper?
A versatile After Effects extension for **advanced shape manipulation**,
enabling users to **control shapes** through puppet pin or bone-like systems.
The tool integrates **mask structures for precise shape control**, all operating within an **SVG environment**.
This creates a powerful workflow for **dynamic shape animation and manipulation**.
:::
