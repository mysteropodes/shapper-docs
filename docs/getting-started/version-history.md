# Version History

---

## Beta 0.9.9

### ✨ New Features

- **Path Animation (PathKey)** — Full support for path animations. Whether you're using AE expressions or the extension itself, you can now deform shapes using masks — shape transforms and shape keyframes are both taken into account.
- **Magnet Brush** — A proximity-based soft deformation tool. Hold `Ctrl` to smooth tangents.
- **Transform Box** — A multi-point transformation box (rotation, scale, grouped translation) for shape points.

### 🔧 Improvements

- Better pan / zoom
- Improved shape selection when multiple shapes are present
- More precise undo history
- General improvements to data transfer between AE and the extension
- Better influence box positioning, plus a new button to hide them when needed

---

## Beta 0.9.6

### ✨ New Features

- **SVG Mode** — No more JSON file: all data is stored directly in the AE layer
- **Initial State** — Recover the initial position of the mask at any time
- **Link between mask points** — Connect mask points together

### 🐛 Bug Fixes

- Various bug fixes
