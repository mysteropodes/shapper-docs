# Viewer Navigation

The SVG Viewer supports standard zoom and pan controls to help you work comfortably at any scale.

## Zoom

| Action | Result |
|---|---|
| **Mouse Wheel** | Zoom in / out — centered on the cursor position |
| **Double-click** on empty area | Reset zoom and pan to fit the view |

## Pan

| Action | Result |
|---|---|
| **Alt + Drag** | Pan the view |
| **Middle Mouse Button + Drag** | Pan the view |

## Selection in the Viewer

| Action | Result |
|---|---|
| **Click** on a point | Select that point |
| **Click + Drag** on empty area | Marquee selection — selects all points inside the rectangle |
| **Shift + Click** or **Shift + Drag** | Add to current selection |

:::tip
The **marquee selection** only picks up points of the **active mode** (Shape or Mask). Switch with **S** before dragging to target the right type of points.
:::

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `S` | Toggle selection mode (Shape ↔ Mask) |
| `Ctrl + Z` | Undo last change |
| `Alt + Drag` | Pan the view |
| `Double-click` (empty area) | Reset zoom & pan |
